# محرك نماذج عبء العمل

أداة ويب تولّد نموذج عبء عمل افتراضيًا من عدد الموظفين المستهدف (3–150)، وتصدّره إلى Excel منسّق.

إعداد: **AHMAD ZYAD** — تخطيط الموارد البشرية، جامعة الملك خالد.

**الرابط:** https://aasseri.github.io/workload-model-engine/

## الاستخدام
1. افتح الرابط أعلاه، أو افتح `index.html` مباشرة في المتصفح (يلزم اتصال بالإنترنت لتحميل الخط ومكتبة Excel).
2. أدخل عدد الموظفين ثم اضغط «توليد النموذج».
3. اختر «المستوى» (×2 / ×4 / ×6) من لوحة «سجل البحث» لتحديد بداية عدد المهام = المستوى × عدد الموظفين.
4. «سيناريو بديل» يولّد نموذجًا آخر للعدد نفسه.
5. «تصدير Excel» ينزّل ملفًا بورقتي «بيانات الجهة» و«المهام».

## ملف Excel
- **بيانات الجهة**: معلومات الجهة (اسم الجهة، مسؤول الجهة) ثم جدول الموظفين.
- **المهام**: جدول المهام بمعادلات حية، وأسفله «العدد الفعلي» (من بيانات الجهة) و«الاحتياج» (الإجمالي ÷ 1023).

## التطوير
```bash
npm install
npm test
```
الاختبارات تعمل تلقائيًا على GitHub Actions مع كل رفع. راجع `CLAUDE.md` للقواعد والمصطلحات، و`docs/SPEC.md` للخوارزمية، و`docs/CHANGELOG.md` لسجل التعديلات.

## النشر على GitHub Pages
Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.

## تنبيه
النموذج هيكل أولي مشتق من الهدف نفسه، ولا يقيس الاحتياج الفعلي. تُستبدل المهام الافتراضية والأحجام بالمهام الفعلية للجهة قبل الاعتماد.
